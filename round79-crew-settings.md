## From `memory/reports/round-79-report.md` — the parts the spec does not carry

- **Record** `crew_app_settings` (one per business, `_id` = owner_admin_id) — `services/crew_app_settings.py`: defaults (features all on, radius 50 / rule flag, five notifications on, empty onboarding), `validate_patch` (any subset; radius ≥ 30, rule flag|block, note ≤ 2 000, headline ≤ 120; unknown keys ignored), `get_settings` fills defaults and, when no record has set a distance, reads the old Operations `gps_radius_m` once (pushed up to 30); `for_admin` / `for_crew` shapes.
- **Admin routes** `GET/PUT /admin/crew-app-settings`; `POST …/video` (multipart MP4/MOV ≤ 200 MB, optional `duration_s`; `file_storage.upload(folder="Crew app", public=False)` → Drive/OneDrive, else the PTHQ private blob; Replace deletes the previous file; returns `{name, size, duration_s, uploaded_at, provider}`); `DELETE …/video`. Members need the Settings area (`require_crew_app_settings`).
- **Crew routes** `GET /employee/app-settings` → `{features (jobs, timeclock always true), signin, onboarding {headline, note, video: bool}, welcome_seen}`; `GET /employee/onboarding/video` streams the tenant's video with `Accept-Ranges` / 206 (blob: only the asked-for bytes; Drive/OneDrive: `file_storage.download` then the slice), 404 when the business has none or for anyone else's; `POST /employee/onboarding/welcome-seen` stamps `employees.welcome_seen_at` once.
- **Time clock** (`routes/timeclock.py`) — `_site_check` shared by sign-in and sign-out: per-project `geofence_radius_m` first (null = no fence), else `signin.radius_m`; `accuracy_m` accepted on both and stored. Rule `block`: 409 `{code: outside_site, distance_m, radius_m, accuracy_m, message}` when outside **and** `accuracy_m ≤ 25`; otherwise recorded with `outside_radius` as before. Sign-out never refused: `sign_out_outside_radius`, `sign_out_distance_from_site_m`, `sign_out_accuracy_m` stamped and a warning returned. `PUT /admin/profile/operations` no longer writes `gps_radius_m` (the stored value is kept for the one-time fallback); the Timesheets report threshold reads the crew setting, so the off-site bar and Live tab say the same distance as the time clock.

### §8 — silent decisions
1. **Video length** comes from the browser (`HTMLVideoElement.duration` sent as `duration_s`); the server does not probe media. When unknown, the status line shows the size instead.
2. **Headline** capped at 120 characters (the spec caps only the note).
3. **"Refuse it" without an `accuracy_m`** (an older crew build) → recorded and flagged, as a poor reading; `accuracy_m ≤ 25` counts as accurate.
4. **Sign-out flags** live in their own fields (`sign_out_outside_radius`, `sign_out_distance_from_site_m`); the admin "off-site sign-ins" bar keeps counting sign-ins only, as before.
5. **Default distance moved from 100 to 50** — Iter 61's geofence test now reads the business distance from the API instead of asserting 100; a business that had set the old Operations radius keeps it until it saves a distance on the new page.
7. **Platform-access**: members need the Settings area for the admin routes; crew reads pass the crew area check like the other `/employee/*` routes.
